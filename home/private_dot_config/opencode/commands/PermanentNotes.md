---
description: 把本次会话的知识点整理为 WikiSpace 的 PermanentNotes 永久笔记
---

先加载 `tiddlywiki-permanent-notes` skill，严格按其中的流程、字段和格式执行。

任务：把当前会话里的问答内容整理成永久笔记。

- 主题：$ARGUMENTS。为空时自己从对话中提炼；有值时以它为准。
- 只保留可复用的知识：结论、原因、做法、边界条件与踩坑。不复述对话过程，不写“用户问 / 我答”。
- 一条笔记只讲一个观点。对话确实包含多个独立主题时，拆成多篇分别写入并一起汇报，不要硬塞成一篇。
- 标题不加日期；正文用 WikiText，不用 Markdown 语法。
- 写入前先查重：已有同名或同主题笔记时，说明情况并问是改写还是另起一篇。
- 写完后运行 skill 的 `check_note.py`，把结果一并汇报。
- 汇报内容：文件路径、链接了哪些已有笔记、未解决的警告、文件尚未提交。不要自动 git add / commit / push。

如果整段对话只是操作或闲聊，没有值得沉淀的知识点，就直接说明，不要为了产出而编造笔记。
